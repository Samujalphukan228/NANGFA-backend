# Restaurant Backend System

Simple backend system for managing restaurant operations like menu, orders, users, and reservations.

## Finance module

The restaurant now has a full finance/profit management module for an
**accountant** role: custom spending categories, daily entries, linked sales,
sale adjustments, expenses, personal expenses, profit and savings (daily and
cumulative).

See [FINANCE_API.md](./FINANCE_API.md) for the full API, formulas and setup.
